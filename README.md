#  SkyCast – Weather App

##  About the Project
SkyCast is a weather application developed using Kotlin for Android. It is designed to help users check weather conditions and access weather information through a simple and user-friendly interface.

##  Features
- User-friendly interface
- Weather information display
- Simple and intuitive navigation
- Android app development using Kotlin

##  Tech Stack
- **Programming Language:** Kotlin
- **Platform:** Android
- **Build Tool:** Gradle

##  Project Objective
The goal of SkyCast is to build a practical weather application while strengthening my Android development, Kotlin programming, and UI design skills.
